# Three-system prototypes

These connected, no-build pages demonstrate the three mode contracts without a model API or rules engine:

- [`deck-coach/`](deck-coach/README.md) — qualitative deck diagnosis and eight-section primer;
- [`rule-consult/`](rule-consult/README.md) — cited unofficial rules consultation;
- [`p2a/`](p2a/README.md) — human-confirmed Player 2 decision ledger.

Open any `index.html` directly in a normal desktop browser. Each page keeps its working record only in the current tab and exports a versioned artifact. No page uses network requests or browser persistence.

They also share [`shared/engine-check-view.js`](shared/engine-check-view.js), the read-only renderer for the `engine-check.v1` envelope, with [`shared/engine-check-view.css`](shared/engine-check-view.css) for its presentation. It renders all five outcomes — `supported`, `illegal`, `unsupported`, `decision_required`, `invalid_input` — and always shows the coverage limits and the `official_status` / `role` / `state_effect` triple alongside the result, because a bounded consistency check read without its bounds is the failure this component exists to prevent. On a `decision_required` result it presents the pending choice and its options without ranking, defaulting to, or selecting any of them; the choice stays with the human, and a consuming page still owes its own confirmation step.

Its demo data in [`shared/engine-check-fixtures.json`](shared/engine-check-fixtures.json) is generated by running the real engines, not hand-written: regenerate it with `python3 skill/scripts/build_engine_check_fixtures.py` after any change to the engines or the envelope. The pages themselves still run no engine.

All three pages share [`shared/theme.css`](shared/theme.css) and [`shared/i18n.js`](shared/i18n.js). The visual shell follows the RiftBoundC website's Ember & Aged Gold palette, 1560px product frame, Traditional Chinese font stack, square controls, and thin-border card language. Traditional Chinese is the default interface; the `EN` button switches the complete in-tab presentation to English without adding browser persistence.
