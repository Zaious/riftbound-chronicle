# Deckbuilding

"The game" isn't one fixed card pool — which cards are actually legal depends on which environment you're building for, and this book explicitly supports two (see "Which environment: pick before answering," below) rather than silently assuming one. Taiwan's pool is a regionally-lagged slice (only Set 1 — OGN, plus its OGS and ARC companion products — has shipped physical product there, with the Constructed ban list layered on top); this isn't a Taiwan quirk, it's what happens to every region on its own localization track, see `references/regional-legality-model.md` for the general pattern and why it will recur (Korea next, September 2026). Global Standard, by contrast, has no lag — everything released so far is legal. Neither "Taiwan's practical framing" nor "Global Standard" needs to be the assumed default; pick deliberately.

Two separate concerns, don't conflate them: *is a card legal* (below) and *is a deck well-built* (methodology, further down). Answering only the first question makes this a rules checker, not a deckbuilding advisor — the point of this book is the second half.

Do not reason about this game from general TCG intuition or memory of what Riftbound looks like elsewhere without checking. Every claim about a specific card's cost, effect, or legality has to trace back to an actual local card database or the live official source — an invented claim about card text is a real failure mode for this kind of tool, not a hypothetical one, so verify before stating. (If this deployment has a private companion file binding a specific local database path, use that; otherwise use whatever card dataset ships alongside this skill.) General deckbuilding *methodology* (below) is sourced from outside the repo and cited accordingly — cite it as community/publisher analysis, not as verified game text the way a card's printed effect is.

## Which environment: pick before answering

This book supports two concrete environments out of the box, with genuinely different legal pools — don't default to one silently:

- **Taiwan** — a regionally-lagged pool (OGN + OGS only; ARC is a same-name-reprint source, not a third legal set — see below). See below.
- **Global Standard** — the official, all-currently-released-sets Constructed format most of the world plays. See below.

**How to pick**: if this deployment has a private companion file naming a default environment (e.g. a Taiwan-specific site defaults to Taiwan for all its own visitors), use that. Otherwise, infer from context — the question's language, an explicit "in Taiwan" / "globally" / a named region — and if it's genuinely ambiguous, ask rather than assume. Answering a Global Standard question as if it were Taiwan's restricted pool (or vice versa) produces a confidently wrong answer, not a roughly-right one — these pools differ by three whole sets' worth of cards.

Both environments are instances of the same underlying problem — a market's real legal pool isn't a fixed fact, it's set by release/localization/ban-list state that moves over time. The reusable reasoning behind both — how to work out *any* region's real legal pool, including ones not listed here yet — lives in `references/regional-legality-model.md`; read it once, since the same method applies again the day either environment's facts change (a new Taiwan set, a new global set, a new ban wave).

### Environment: Taiwan

Taiwan's "one set behind" situation isn't a quirk of this one market — it's what happens whenever Riftbound enters a market whose localization deal runs on its own clock, and it will recur elsewhere (Korea launches September 2026 the same way). What follows is today's concrete instance (last verified 2026-08-18) — treat it as a dated snapshot and re-verify against a live/current source before relying on it (a private companion file, if this deployment has one, names the exact local tracking doc).

- **Legal sets**: OGN and OGS, the two Standard-format sets (Tournament Rules 601.3.c) physically available in Taiwan. OGS ("起源特別版") is the 24-card Proving Grounds (試煉之地) companion set — four fixed 54-card starter decks (Annie/Garen/Lux/Master Yi), one printing each, no OGN/other-set sibling. **Treat both as part of the baseline pool, not a special case** — a serious player pursuing real deckbuilding has very likely already bought what they needed, and four of the strongest Legends in the current pool are OGS-exclusive, so excluding it by default would silently cripple half the interesting deckbuilding space. One thing worth knowing: the Proving Grounds box sold out roughly a week after Taiwan's launch, so it's scarcer and may carry scalper pricing — mention that in passing if it comes up, don't gate recommendations behind asking whether the person owns it. **ARC (the Arcane crossover promo bundled during the Set 1 window) is not itself a legal set** — it doesn't confer Standard legality the way OGN/OGS do, in any region. What it actually contributes: Tournament Rules 601.2.a permits a card that shares a name with a card from a legal set, even when the specific copy is an ARC printing — so an ARC same-name reprint of an OGN/OGS card is fine to play on that basis (not because ARC itself is Standard), while an ARC card with no such match, or an overnumbered ARC reprint (601.2.c), isn't legal regardless of physical availability. See `regional-legality-model.md` for the general version of this reasoning.
- **Everything else** (SFD, UNL, VEN, RAD, plus FND which is a Simplified-Chinese-only promo series and was never in scope for Taiwan regardless of set order) is off the table — not shipped in Taiwan as of last verification, and there's no confirmed date for Taiwan's Set 2. Check a card's set code against a real local or live card database before stating legality either way.

### Environment: Global Standard

"Standard" is Riftbound's official name for the main, non-regionally-limited Constructed format — every currently-released set is legal, no lag, no companion-product ambiguity. This is the environment almost every non-Taiwan community writeup (riftbound.gg, RiftJudge, etc.) is implicitly talking about, so if a question's source or phrasing doesn't scream "Taiwan," this is the safer default outside a Taiwan-specific deployment.

- **Legal sets** (verified against Tournament Rules 601.3.c, 2026-08-17, re-check a live source since this moves roughly every 2-3 months): **OGS, OGN, SFD, UNL, VEN** — the official Standard-format list, five sets, no more. **ARC is not on that list** — a Set-1-window crossover promo product, it doesn't itself confer Standard legality the way the five sets above do. That doesn't make every ARC card unusable, though: Tournament Rules 601.2.a permits a card if it shares a name with a card from a legal set, even when the specific copy in hand is printed in a non-legal product like ARC — so an ARC printing of a card that's *also* printed in one of the five sets above is fine to play, on the strength of the name match, not because ARC itself is Standard. Two related traps worth stating explicitly: 601.2.c — an *overnumbered* reprint (collector number outside a set's normal range, e.g. 300/250) does not automatically gain that set's format legality just by being printed there; and 601.2.d.2 — at low OPL (Casual-tier events specifically, see Tournament Rules 205 for the three OPL tiers: Casual/low, Competitive, Professional/high) a player using the *exact*, unmodified configuration of an official preconstructed deck product may play cards on it that would otherwise be banned, but loses that exemption the instant anything is changed or a sideboard is added. RAD (Radiance, Set 5) joins the legal-set list on its release date, 2026-10-23; before that date it isn't legal yet even though preview cards may already exist in a card database. First rotation isn't until Set 10 (early 2028, when OGN/OGS and everything else from 2026 cycles out together) — not a near-term concern, but worth knowing this format isn't permanently unbounded.
- **No regional gap to reason about** — this environment is the leading edge Taiwan (and every other regionally-lagged market) is behind. Don't apply the "compound gap" reasoning from `regional-legality-model.md` here; that's specifically about what a *lagging* region inherits, and Global Standard isn't lagging anything.

### Shared across both environments

- **Ban list**: treat whatever this deployment's single source of truth for the ban list is as authoritative — a private companion file, if one exists, names it. This list is global by *region* (Riftbound bans apply company-wide, identically in both environments above — see `regional-legality-model.md` point 5) — **but it is not one single list across formats.** The live official ban list is actually two separate tables, 1v1 Constructed and 2v2 Constructed, each with its own "last updated" date and its own contents; a card banned in one is not automatically banned in the other. Concrete current example (verified live, 2026-08-17, unchanged since the list's own 2026-07-16 last-updated date): **Master Yi, Wuju Bladesman is banned in 2v2 Constructed only** — completely legal in 1v1 Constructed, where the Legends category of the ban table is empty. Always confirm which format's table applies before telling someone a card or Legend is banned. Read it fresh each time; if there's any doubt the local list is current, cross-check against the live official ban list at `https://playriftbound.com/en-us/rules-hub/` (see the library's top-level "route, don't snapshot" rule) before telling someone a card is safe to play in a real event.
- **Construction legality**: exactly 40 main deck (including the Chosen Champion), exactly 1 Legend, exactly 12 runes (separate pile, no copy cap, ideally split 6/6 — see methodology), exactly 3 Battlefields, max 3 copies of any card name — Tournament Rules 601.1.c.3 specifically states this cap applies to the *combination* of main deck and sideboard, not the main deck alone (the Champion's extra copies count toward its own cap). Where a sideboard is allowed at all, Tournament Rules 601.1.c.1 caps it at 10 cards or fewer. A deck's two Domains are fixed entirely by its Legend — Riftbound does not allow the "however many colors you want" flexibility some other TCGs have. Verify this against the official Core Rules PDF (or a private companion's pointer to the local encoded ruleset) rather than restating from memory if precision matters.

## Deckbuilding methodology

This is the part that separates "knows the rules" from "can actually help build a good deck." Sourced from riftbound.gg's Deckbuilding 101 and archetype-theory writeups (community/publisher analysis, cite as such, re-verify if it's been a while since 2026-08 — the game is young and this thinking is still settling) plus the transferable core of general TCG theory (card advantage / tempo trade-offs are near-universal across the genre).

**Start from the Legend, not from a pile of strong cards.** The Legend fixes your two Domains and provides an ability that should shape everything else — synergy with that one ability beats a collection of individually powerful cards pulling in different directions. Read the Legend's and both Champion options' printed text before suggesting anything; the ability itself usually signals the intended archetype (a unit-buff-on-defense Legend signals midrange/control, a discard-to-draw Legend signals aggro) more reliably than the Domain pairing alone. Two Legends can share both Domains and still want opposite gameplans — don't assume Domain pair alone determines archetype.

**Three archetypes, defined by path to the same win condition.** Points come from capturing and *holding* Battlefields — this is not a damage race, and that changes what "a good curve" means versus other TCGs. Aggro floods the board and forces early decisions before the opponent stabilizes. Control denies space and grinds out points by holding Battlefields over time. Combo plays a patient setup game, then detonates a turn that swings multiple points at once, trading consistency for ceiling. State which one a deck is going for explicitly — a deck that doesn't commit to a lane usually just plays worse versions of all three.

**This three-way split is this book's own framework, not a guarantee that real practice sorts as cleanly.** Verified 2026-08-17: real community coverage of Darius, Hand of Noxus described most competitive lists as "tempo-engine decks, not pure aggro" — a distinct, commonly-used label this framework doesn't have room for, even though a pure text-structural read of Darius's immediate, same-turn-condition kit points straight at "aggro." When Tier 2 verification (see below) surfaces a real community label that doesn't map onto aggro/control/combo, report that real label plainly rather than force-fitting it into one of the three — the mismatch is itself useful information, not noise to smooth over.

**A related, structurally deeper trap: when a Legend's two Champions read as pulling toward different archetypes, that's a testable hypothesis, not evidence that real deckbuilders treat both as comparably-viable alternative decks.** Verified 2026-08-17 on Master Yi, Wuju Bladesman, re-verified with real citations the same day: a pure Tier-1 reading of his two Champions (Meditative's rune-hoarding vs. Honed's mobility) reads as a genuine fork into two different lanes. Real practice has converged on something narrower and more specific instead — a single, extensively-proven "solo-hold-one-Battlefield" strategy (Top 8 at all four North American Unleashed Regional Qualifiers specifically — a first-pass version of this claim overgeneralized to "every" RQ, which the same source's own Chinese-Regional results don't support) built around Ambush synergy with the wider card pool, where Honed's mobility supports securing that one Battlefield rather than defining a separate competing gameplan. The re-verification also caught a second overclaim worth naming directly: the first-pass correction stated this strategy doesn't depend on any set-exclusive piece, which is false — real coverage credits Unleashed-specific cards with turning this from a merely-competitive line into a Top-8-caliber one, so its highest-level execution is itself subject to the regional-set-lag reasoning below, not exempt from it. Tier 1 cannot resolve which situation it's looking at on its own, structurally — whether an apparent Champion-split is a real fork or a false dichotomy often depends on synergy with cards *outside* the Legend+Champion kit, which is outside Tier 1's scope by definition, not a gap that more careful text-reading closes. Treat any "this Legend splits by Champion choice" conclusion in this book or in `legend-construction-logic.md` as an unverified Tier-1 hypothesis until Tier 2-confirmed, not a settled finding — this applies to every entry currently marked as a split in that catalog, not only Master Yi's. And treat a Tier 2 finding itself as provisional until independently re-checked with real citations — as this one just demonstrated on itself.

**On two-Domain pairs**: Domains pair into three official *opposite* axes — Fury↔Calm, Mind↔Body, Chaos↔Order — and `compute_domain_stats.py`'s dual-domain count (109 cards total, from the same reproducible 949-card population as the table above) found each opposite pair sitting at exactly 3 cards, versus 6–11 for every non-opposite pairing (roughly a 2–3× rarity gap) — the same direction as an earlier, unreproducible count of this same fact (which had found a ~3–4× gap against a different dataset), confirmed again independently rather than just repeated. Opposite pairs aren't banned, just historically rare — the first Legend ever printed spanning an opposite axis (Kai'Sa, Daughter of the Void doesn't count, she's Fury+Mind, non-opposite; the actual first is Kennen, Heart of the Tempest, Chaos+Order) didn't appear until Set 4. Treat an opposite-axis pairing as thinner-supported by default, not unplayable. Beyond that population-rarity fact, this book deliberately does **not** carry a tactical playbook per specific pair (15 possible combinations) — two Legends sharing the same pair can still want opposite gameplans (see "Start from the Legend" above), so a pair-level generalization risks exactly the overclaiming this methodology otherwise avoids. Use the table above to form a hypothesis about a pair's *texture*, then verify against the specific Legend and the actual legal card pool for the environment in question (a much larger sample in Global Standard than in Taiwan) — don't state pair-level personality as fact without checking the Legend in front of you.

**Deriving a specific Legend's identity — a repeatable method, not a lookup table.** This applies to every Legend in the pool (roughly 50 as of 2026-08 and growing every set) — not just the two worked below. There is deliberately no pre-written entry for each one: a static per-Legend writeup is exactly the kind of thing this skill's "route, don't snapshot" discipline exists to avoid — it would read as current while quietly going stale the moment a cited card gets banned or a new set shifts what's typical, with nothing in this repo to notice or refresh it. Run this process live, for whichever Legend is actually being asked about, every time:

**Two things this process gets wrong by default, confirmed by real checks (`references/verification-log.md`), not theoretical caution — apply both to every run, not just when Tier 2 happens to contradict something:** (1) State the archetype label as *this text's best hypothesis*, not a fact — "reads as aggro" rather than "is aggro." Real community terminology sometimes uses a label this book's three-way framework doesn't have (tempo is the confirmed case). (2) When the two Champions read as pulling toward different archetypes, say so as a hypothesis about two *possible* decks, not as a finding that real deckbuilders treat both as comparably viable — whether it's a genuine fork or one dominant strategy with the other Champion playing a supporting role often depends on synergy with cards outside the Legend+Champion kit, which this process cannot see by construction. The Kai'Sa worked example below has since been Tier 2-checked itself — and then re-checked again with real, dated citations, which changed the answer a second time (see the log). Read its method for deriving identity from primary text, which held up through both rounds, not either of its Champion-split conclusions along the way, the first of which turned out wrong and the second of which was also wrong in a different way. That's not a flaw in the example; it's the most honest demonstration in this book of why a Tier 2 finding needs the same skepticism as a Tier 1 one until it's actually been checked against real, sourced, dated evidence.

A community guide's summary of "what makes Legend X tick" is a fine sanity check, but it goes stale (new support cards, bans, reprints) and it isn't source text. The reliable version is: read the Legend's own ability, both Champion options' abilities, and (if checking further) the Champion Tag's Signature cards — the shared resource, timing window, or trigger condition across all of them *is* the Legend's identity, derived independently rather than recalled.

*Worked example — Kai'Sa, Daughter of the Void (Fury+Mind).* Her Legend ability: `Exhaust: Reaction — Add a rainbow rune, usable only to play spells.` That alone signals a spells-heavy plan enabled by fixing mana outside her own two Domains. Her two Champions confirm it from different angles rather than contradicting it: **Kai'Sa, Survivor** (Fury) is `Accelerate. When I conquer, draw 1` — the more aggressive, board-forward option, still paying off through card draw rather than raw stats. **Kai'Sa, Evolutionary** (Mind) is `Ganking (can move battlefield to battlefield). When I conquer, you may play a spell from your trash with Energy cost less than your points without paying its Energy cost, then recycle it` — free-Energy spell recursion, directly synergizing with the Legend's own spell-cost-easing ability. That much — a Legend built around casting a lot of spells cheaply and recurring them — is text-derived and holds up. This example has now been corrected twice, and both corrections are left visible here on purpose rather than only keeping the final one, because the sequence itself is the actual lesson.

**First correction (2026-08-17)**, on the original "two comparably-weighted lanes" reading: real coverage described one of the game's most-played archetypes as spell-based, built around cheap damage spells (community-cited: Hextech Ray, Falling Star, Void Seeker), and this first-pass correction concluded the two win paths (grind via removal/cards, or close quickly) "aren't tied to which Champion was chosen."

**Second correction (2026-08-17, same day, on independent re-verification with real citations — `references/verification-log.md`)**: that specific replacement claim was itself wrong, not just under-cited. A real deck-tech source (cardsrealm.com) covering exactly the archetype described above names **Kai'Sa, Survivor** specifically as "one of the most critical cards" in it — not a swappable option — and treats **Kai'Sa, Evolutionary** as the anchor of a *different*, separately-discussed deck entirely, not an alternate build of the same one. So the honest picture is closer to the original Tier-1 read than the first correction allowed: the two Champions do point toward two different decks, just not symmetrically — one (Survivor's) is the specific, popular, spell-tempo archetype described above; the other (Evolutionary's) is a distinct build this source doesn't cover in the same depth. The same re-verification also caught a staleness problem worth naming on its own: "one of the most-played archetypes" was true as of a December 2025 source, but the same platform that made the "most-played" claim (riftbound.gg) had, by its own July 2026 update, downgraded her to "a Tier 3 legend" with "momentum completely stopped in June" — a five-week-old claim turning stale is exactly the citation-vs-derivation risk this book's methodology exists to catch, demonstrated on its own flagship example rather than only described in the abstract.

Signature cards (tagged to whichever Champion is chosen) are worth checking on top of this, per the Champion/Signature guidance above. The lasting takeaway isn't "Kai'Sa's identity is now settled" — it's that a Tier 2 correction is exactly as provisional as the Tier 1 hypothesis it replaced, until *it's* independently re-checked with real, dated citations, which is what finally happened here.

**Identity alone reads the surface. What a decklist actually needs — the construction logic — is a deeper reading of the same text, not a different source.** Don't stop at "what does the ability say"; ask what its *timing*, its *conditions*, and its *target scope* structurally require to function. A trigger that fires "at end of turn" pays off over multiple future turns, not this one — that's a fact about the deck's shape, not a vibe. A trigger that requires something to already be in the trash structurally demands an earlier, cheaper play to feed it — that's a resource requirement, derived, not guessed. This reasoning is as permanent as the printed card — it's a logical consequence of text that doesn't change, so unlike a specific recommended card, **it doesn't go stale.** What actually expires is only ever a guide's *illustration* of the pattern (a specific named card that later gets banned), never the structural pattern itself, because the pattern was never sourced from the guide to begin with — the guide is a place to *check* the derivation against what real play discovered, not the place the derivation comes from.

*Worked example — Annie, Dark Child (Fury+Chaos).* Surface identity first: Legend ability `At the end of your turn, ready up to 2 runes` (corrected 2025-10-28 by official errata from `ready 2 runes`, applied here 2026-08-17 — see `references/errata_overlay.json`); **Annie, Fiery** (Fury) `Your spells and abilities deal 1 Bonus Damage`; **Annie, Stubborn** (Chaos) `When you play me, return a spell from your trash to your hand`. Read only that far and the honest summary is "spell-centric, Fury-burn or Chaos-recursion lean" — true, but still the surface.

Now push into the structure of each piece:

- The ramp trigger is **end of turn**, not on play and not immediate — its payoff is next turn's bigger play, not this turn's. A deck built around a compounding, turn-over-turn resource edge structurally wants a win condition that also compounds over time (holding/repeated conquest) rather than one explosive alpha strike — that conclusion comes from *when* the ability fires, nothing else.
- Stubborn's recursion is conditioned on a spell **already sitting in the trash** — it does nothing without one. That's a resource dependency: the deck needs a cheap, early-castable interaction spell in the curve *before* she's likely to land (she costs 4), purely so there's something to recur. This is a requirement the ability's own wording imposes, not a recommendation borrowed from anywhere.
- Fiery's bonus damage applies to "spells **and abilities**," not spells alone — broadening the payoff to triggered/activated unit abilities, not a pure spellbook.
- Cross-check against the Domain table above: Fury carries the pool's highest direct-damage share (17%) and Chaos the pool's lowest destroy-removal share (10%). So this deck's removal is structurally damage-based (Fury's job), not destroy-based (that's Order's job elsewhere) — Fiery's bonus damage *is* the deck's removal tool, not a separate add-on.

Put together, purely from the printed text plus the Domain table already built: this Legend wants a cheap, efficient early interaction spell (to feed Stubborn), a game plan that compounds advantage over several turns rather than one big turn (implying Battlefield/win-condition choices that reward holding or repeated conquest, not a one-shot payoff), and damage-based rather than destroy-based removal. None of that required reading a single guide.

**Where a guide earns its place is confirming the derivation, and that's also where the staleness risk actually lives — in the confirmation, never in the logic.** Two independent write-ups of a Houston Regional Qualifier-winning Annie, Dark Child list (covered separately by cardsrealm.com and riftbound.gg, re-verified with real citations 2026-08-17) describe exactly this shape — conquering Battlefields early, recurring a cheap interaction spell the same turn Annie lands — which is the derived pattern above, confirmed by real results rather than only by reasoning. One specific phrase from an earlier pass of this section, "a Fury/Chaos tempo shell," doesn't actually appear verbatim in either source on re-check: cardsrealm.com's coverage leans on "combo," "value," and "explosive" language, while riftbound.gg's separate Houston preview piece uses real tempo language ("the flexible tempo tool," "an immediate tempo spike") without pairing it with "shell" — close in spirit, not a real quote, and shouldn't have been presented as one. Those same write-ups also name specific Battlefields — including **The Arena's Greatest** and **The Dreaming Tree** — and both are now banned (see the "compound gap" section in `regional-legality-model.md`; this is that phenomenon caught in the act, not a hypothetical). What went stale was the *citation*, not the derivation: "wants a Battlefield that rewards holding/incremental conquest" is exactly as true today as it was before the ban, and it's still what to search the legal Battlefield pool for. That's the whole reason to keep the derived structural pattern and the guide's specific examples as two separate things instead of one — the same discipline the ban-substitution workflow (below) applies card-by-card, done once in advance at the Legend level so it doesn't need redoing from scratch every time someone asks about this specific Legend.

**This has already been run once across the current roster.** [`references/legend-construction-logic.md`](references/legend-construction-logic.md) applies exactly the Tier-1 structural derivation above (not the Tier-2 guide-cross-referencing) to the other 46 Legends currently in the pool — check there first before re-deriving one from scratch. That file is a thin index (name, archetype label, win-condition summary, and grep-able mechanic tags for finding a comparable or counter-matchup Legend without opening every entry), one row per Legend, each linking to its own full write-up under `references/legends/`. The full write-up names the archetype lane the Legend commits to, describes how the deck actually unfolds turn to turn, and states explicitly what its engine converts into points — that's the actual deliverable, not a card-text summary or a check against the Domain-personality table (which barely appears there, deliberately: it answers a different, less useful question than "which archetype and how does this play out"). **Main deck composition** (numbers are a starting point to adjust, not a hard formula): roughly 9–12 low-cost units so the early game is never empty-handed, 6–9 low-to-medium cost spells (many spells are reactive — a single well-timed one often decides a close Showdown) plus a few bigger ones as the ceiling, and more units than spells overall since units are what actually holds Battlefields. Because the win condition is board/Battlefield control rather than a damage race, over-investing in expensive endgame closers at the cost of an empty early game is a sharper mistake here than in a life-total-race TCG — a deck that can't contest the board on turns 2–4 may never get to cast its finishers.

**Turning "roughly 9–12" into an actual number — the hypergeometric math, correctly parameterized.** These composition heuristics are calibrated intuition; when a real decision hinges on "how likely am I to have this by turn N," compute it rather than guess, and get the population right or the number is worse than useless. The mechanics that matter here, verified against the official setup sequence: **the Legend never enters the deck at all** (placed directly in the Legend Zone at setup) and **the Chosen Champion is pulled into its own Champion Zone before shuffling**, not drawn and not part of the shuffled pile — so a 40-card Main Deck (the deckbuilding-legality count, which does include the Champion) actually shuffles and draws from **39 cards**. Opening hand is 4 cards, with a mulligan that bottoms up to 2 and draws that many replacements (a wash on card count, not a clean "extra draws" bonus — model the pre-mulligan probability as the honest baseline, and treat the mulligan as improving your odds of a *keepable* hand rather than a clean addition to the hypergeometric sample size).

Standard hypergeometric setup: population `N = 39`, successes in population `K` = copies of the specific card in the deck (1–3), sample size `n` = cards seen by a given point (4 for the opening hand; add 1 per Draw Phase after that). In **1v1 Constructed specifically**, the player going first *does* draw on turn 1 (verified against a specific ruling on this exact question — don't assume a "first player skips their first draw" convention carried over from other TCGs); the player going second channels an extra Rune on their first turn to compensate, but that's the separate Rune Deck/resource pool, not the Main Deck, so it doesn't change this count. **This changes in 4-player/2v2 formats**, where the first player *does* skip their first draw — recompute `n` accordingly if the question is about that format, don't reuse the 1v1 table. Probability of drawing **at least one** copy by that point:

```
P(at least one) = 1 − C(N−K, n) / C(N, n)
```

Computed reference table for a 39-card deck (1v1, so `n` = 4 at the opening hand, +1 per turn thereafter for either player):

| Copies (`K`) | Opening hand (`n=4`) | Turn 3 (`n=6`) | Turn 5 (`n=8`) | Turn 7 (`n=10`) |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 10.3% | 15.4% | 20.5% | 25.6% |
| 2 | 19.7% | 28.7% | 37.2% | 45.2% |
| 3 | 28.4% | 40.3% | 50.8% | 60.0% |

These are exact `1 − C(N−K,n)/C(N,n)` values for `N=39`, computed, not recalled or estimated — recompute rather than pattern-match to this table if `N` differs (a Champion or Legend interaction changes the effective population, a card that tutors/tucks changes what "drawing" even means for that specific case). The table exists to show the *shape* worth knowing — the swing from 2 to 3 copies matters most early (opening hand: 20% → 28%) and least late (turn 7: 45% → 60% still a big gap, but by then most decks have already committed to a plan) — not to be quoted as if every deckbuilding question maps onto exactly these five numbers.

**Rune split**: start from 6 runes of each Domain, and skew toward 5/7 or 4/8 only when the deck's actual power-cost distribution across the two Domains is genuinely lopsided (one Domain carrying most of the expensive cards) — check the real distribution against your card database rather than guessing.

**Card-quality-by-rarity as a deckbuilding role, not a power ranking**: Commons are the consistency backbone (early plays, keeps the draw engine functional) — a deck too light on commons will feel inconsistent even with strong top-end. Uncommons bridge early setups into the midgame. Rares often define the actual win condition. Epics are typically 1–2 copy, high-cost, game-ending plays, not something to build a deck's core around.

**Chosen Champion and Signature cards**: a Legend has two Champion options in its Domains — pick whichever matches the deck's committed gameplan, not automatically the higher-rarity one. Every Legend also has Signature cards tied to its Champion Tag (up to 3 total, regardless of which specific Champion is chosen) — these are frequently above the average power level for their cost and worth checking even when not obviously "needed."

**Battlefield selection**: pick from two angles — which three synergize best with the deck's own plan (a control deck wants different Battlefield effects than an aggro one), and, for best-of-three, how the pick sequences across game 1 (often randomly assigned), game 2, and a potential tiebreaker game.

**Process**: don't judge or swap cards after one or two games. A deck's real strengths and losing patterns only show up over repeated play — "why did this deck lose" is more diagnostic than "did this deck win."

**Argue both sides before recommending a specific cut.** "Should I cut card X for card Y" has a real answer, but a single pass of reasoning tends to anchor on whichever case gets generated first and state it with more confidence than it earned. Before concluding, explicitly build the case *for keeping* X (what role does it fill, what does the deck lose without it, is there a matchup or line where it's specifically the right answer) and the case *for cutting* it (what does Y do that X doesn't, does the deck's actual curve/copy-count support running both), then weigh them against each other in the answer — don't silently pick a side and rationalize it. This matters most exactly where it's tempting to skip it: a popular community-recommended swap, or a card that "obviously" looks worse on paper. Say plainly when the two cases are close rather than manufacturing false confidence in either direction — "this is genuinely close, here's what it depends on" is a more useful answer than a coin-flip stated as certainty.

## "Does this classic/tournament deck still work?" — the ban-substitution workflow

Someone points at a known decklist (an official RQ Top 8, a practice deck already in this site's guides, something pasted from overseas) and asks if it still holds up — in whichever environment applies (see "Which environment: pick before answering" above; this workflow runs identically in either, only the legal-set check in step 1 differs).

**Same workflow, same steps, when the trigger is "not released here yet" instead of "banned."** A supporting card can be unusable in a given environment for two structurally different reasons that need the identical fix: it's banned everywhere, or it's from a set the environment doesn't have yet (Taiwan specifically — see `regional-legality-model.md`). Both are "legal pool doesn't include this card" — run the exact same steps below regardless of which reason applies, don't treat regional set-lag as a different, special case. This matters most for `legend-construction-logic.md` entries once they've been through real Tier 2 verification (see `references/verification-log.md`): if a confirmed real strategy for a Legend depends on a specific supporting card, note which set that card is from — not as a legality judgment baked into the catalog entry itself (that would duplicate `regional-legality-model.md`'s own job and drift from it), but so a later reader asking "can I build this in Taiwan" can run this exact workflow instead of the finding just silently not applying. The dependency fact itself doesn't go stale (which card a strategy needs never changes); only whether a given region has that card does, which is exactly what this workflow and the environment logic above already track.

**Default assumption, not an edge case**: anything sourced from the game's early global history (roughly its first ban wave's worth of time, i.e. anything that looks like it predates 2026-03-31) should be assumed to need this workflow, not just checked in passing — see `references/regional-legality-model.md`'s "compound gap" section for why a newly-arrived region's Set 1 pool already has some of its own defining cards pre-banned. That reasoning applies most sharply to the Taiwan environment; Global Standard has no regional lag, but a pre-ban-wave decklist still needs the same card-by-card ban check there too. Don't skip straight to "looks legal" on a classic decklist without running it through the steps below.

1. Check the Legend/Champion first, separately from everything else, against whichever environment's legal-set list applies. In Taiwan, if it's from a set outside OGN+OGS+ARC entirely, the honest answer is "not buildable here at all" — don't bury that under a list of minor substitutions. In Global Standard this step almost never disqualifies a Legend (nearly everything released is legal there) — it mainly matters for a genuinely new/preview set that hasn't released yet.
2. Check every other card against the actual current ban list — get the exact banned names from the real list, not a guess or a memory of an older version.
3. For each banned non-Legend card, read its actual printed effect and place it in the methodology above: what role was it playing (an aggro deck's cheap presser, a control deck's stabilizer, a combo piece, a Battlefield's conditional bonus)?
4. Search the legal, non-banned pool for cards in the same Domain(s) filling a similar role at a similar cost — not just a similarly-costed card, the same *job*. Only recommend a specific card once you've confirmed its real text and legality; don't suggest from vague recollection.
5. Give the honest verdict: still fully functional with swaps, meaningfully weaker but playable, or the archetype's core game plan doesn't survive without that piece. All three are legitimate answers — don't default to reassurance just because it's more pleasant to hear.

## No metagame-defining claims

No win-rate/play-rate/Tier/"best deck" claims anywhere in the text, in either environment. This applies even where meta data plausibly exists (tournament results in Global Standard, for instance) — Riot's Developer Portal policy for Riftbound apps (`developer.riotgames.com/policies/riftbound`) explicitly restricts apps that "publish or retain metagame-defining data" (win rate / play rate / matchup win% differential), independent of whether the data is available. Staying qualitative is what keeps this kind of tool inside the Approved-use "Deck builders / Card libraries" category instead of drifting into the restricted one.
