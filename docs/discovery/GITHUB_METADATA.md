# GitHub discovery metadata

Keep the repository name as `riftbound-chronicle`. It is the product identity,
and players searching for Riftbound should see that term first. Adding `agent`
to the repository name would improve one keyword for AI developers but make the
project look like a generic agent repository to the primary TCG audience.

Use the following GitHub About description instead:

> Riftbound AI Skill: deck coach, cited rule consult, and human-confirmed Player 2 agent for physical TCG practice.

Suggested topics:

```text
riftbound
riot-games
trading-card-game
tcg
deck-building
gameplay-coach
rules-consult
ai-agent
claude-skill
player2-agent
```

The README title, the Skill description, the three mode names, and the prototype
page titles already carry the high-value search phrases. Update the About field
and topics in GitHub repository settings; those fields are repository metadata,
not files that a commit can reliably change.
