# Rule Consult static prototype

This no-build interface demonstrates a cited, unofficial rules consultation. It keeps confirmed facts, assumptions, source locators, analysis, confidence, and escalation separate, then exports `rule-consultation.v1` JSON.

Open `index.html` directly, or serve the folder with any static file server. The model connection is a manual bridge: copy the structured research brief into a Skill-enabled Agent and enter the verified result back into the interface.

The rule-basis step also accepts an optional executable consistency check. Attached checks go into the artifact's `engine_checks` array and are displayed by the shared read-only viewer in [`../shared/engine-check-view.js`](../shared/engine-check-view.js), so an `engine-check.v1` outcome reads the same here as in any other system. The official source remains the answer's authority: a `supported` check does not raise source confidence, and an `unsupported` one means the bounded component abstained, so neither changes the confidence rules the answer step already enforces.

The checks offered in the interface are demonstration data generated by running the bundled engines ([`../shared/engine-check-fixtures.js`](../shared/engine-check-fixtures.js)); the page itself runs no engine.

Validate an exported artifact with:

```powershell
python skill/scripts/rule_consult.py validate path/to/consultation.json
```

The interface has no network/model call, browser persistence, official-ruling claim, or game-state write.
