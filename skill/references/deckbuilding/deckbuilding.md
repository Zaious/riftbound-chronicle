# Deckbuilding

"The game" isn't one fixed card pool — which cards are actually legal depends on which environment you're building for, and this book explicitly supports two (see "Which environment: pick before answering," below) rather than silently assuming one. Taiwan's pool is a regionally-lagged slice (only Set 1 — OGN, plus its OGS and ARC companion products — has shipped physical product there, with the Constructed ban list layered on top); this isn't a Taiwan quirk, it's what happens to every region on its own localization track, see `references/regional-legality-model.md` for the general pattern and why it will recur (Korea next, September 2026). Global Standard, by contrast, has no lag — everything released so far is legal. Neither "Taiwan's practical framing" nor "Global Standard" needs to be the assumed default; pick deliberately.

Two separate concerns, don't conflate them: *is a card legal* (below) and *is a deck well-built* (methodology, further down). Answering only the first question makes this a rules checker, not a deckbuilding advisor — the point of this book is the second half.

Do not reason about this game from general TCG intuition or memory of what Riftbound looks like elsewhere without checking. Every claim about a specific card's cost, effect, or legality has to trace back to an actual local card database or the live official source — an invented claim about card text is a real failure mode for this kind of tool, not a hypothetical one, so verify before stating. (If this deployment has a private companion file binding a specific local database path, use that; otherwise use whatever card dataset ships alongside this skill.) General deckbuilding *methodology* (below) is sourced from outside the repo and cited accordingly — cite it as community/publisher analysis, not as verified game text the way a card's printed effect is.

## Which environment: pick before answering

This book supports two concrete environments out of the box, with genuinely different legal pools — don't default to one silently:

- **Taiwan** — a regionally-lagged pool (OGN + OGS + ARC only). See below.
- **Global Standard** — the official, all-currently-released-sets Constructed format most of the world plays. See below.

**How to pick**: if this deployment has a private companion file naming a default environment (e.g. a Taiwan-specific site defaults to Taiwan for all its own visitors), use that. Otherwise, infer from context — the question's language, an explicit "in Taiwan" / "globally" / a named region — and if it's genuinely ambiguous, ask rather than assume. Answering a Global Standard question as if it were Taiwan's restricted pool (or vice versa) produces a confidently wrong answer, not a roughly-right one — these pools differ by three whole sets' worth of cards.

Both environments are instances of the same underlying problem — a market's real legal pool isn't a fixed fact, it's set by release/localization/ban-list state that moves over time. The reusable reasoning behind both — how to work out *any* region's real legal pool, including ones not listed here yet — lives in `references/regional-legality-model.md`; read it once, since the same method applies again the day either environment's facts change (a new Taiwan set, a new global set, a new ban wave).

### Environment: Taiwan

Taiwan's "one set behind" situation isn't a quirk of this one market — it's what happens whenever Riftbound enters a market whose localization deal runs on its own clock, and it will recur elsewhere (Korea launches September 2026 the same way). What follows is today's concrete instance (last verified 2026-07-19) — treat it as a dated snapshot and re-verify against a live/current source before relying on it (a private companion file, if this deployment has one, names the exact local tracking doc).

- **Legal sets**: OGN, OGS, and ARC together, all three treated as "Set-1-available" — not just OGN+OGS. OGS ("起源特別版") is the 24-card Proving Grounds (試煉之地) companion set — four fixed 54-card starter decks (Annie/Garen/Lux/Master Yi), one printing each, no OGN/other-set sibling. ARC is the Arcane crossover promo bundled during the Set 1 window. **Treat all three as part of the baseline pool, not a special case** — a serious player pursuing real deckbuilding has very likely already bought what they needed, and four of the strongest Legends in the current pool are OGS-exclusive, so excluding it by default would silently cripple half the interesting deckbuilding space. One thing worth knowing: the Proving Grounds box sold out roughly a week after Taiwan's launch, so it's scarcer and may carry scalper pricing — mention that in passing if it comes up, don't gate recommendations behind asking whether the person owns it.
- **Everything else** (SFD, UNL, VEN, RAD, plus FND which is a Simplified-Chinese-only promo series and was never in scope for Taiwan regardless of set order) is off the table — not shipped in Taiwan as of last verification, and there's no confirmed date for Taiwan's Set 2. Check a card's set code against a real local or live card database before stating legality either way.

### Environment: Global Standard

"Standard" is Riftbound's official name for the main, non-regionally-limited Constructed format — every currently-released set is legal, no lag, no companion-product ambiguity. This is the environment almost every non-Taiwan community writeup (riftbound.gg, RiftJudge, etc.) is implicitly talking about, so if a question's source or phrasing doesn't scream "Taiwan," this is the safer default outside a Taiwan-specific deployment.

- **Legal sets** (last verified 2026-08-16, re-check a live source since this moves roughly every 2-3 months): OGN, OGS, ARC, SFD, UNL, VEN — literally everything released so far. RAD (Radiance, Set 5) joins on its release date, 2026-10-23; before that date it isn't legal yet even though preview cards may already exist in a card database. First rotation isn't until Set 10 (early 2028, when OGN/OGS and everything else from 2026 cycles out together) — not a near-term concern, but worth knowing this format isn't permanently unbounded.
- **No regional gap to reason about** — this environment is the leading edge Taiwan (and every other regionally-lagged market) is behind. Don't apply the "compound gap" reasoning from `regional-legality-model.md` here; that's specifically about what a *lagging* region inherits, and Global Standard isn't lagging anything.

### Shared across both environments

- **Ban list**: treat whatever this deployment's single source of truth for the ban list is as authoritative — a private companion file, if one exists, names it. This list is global (Riftbound bans apply company-wide, identically in both environments above — see `regional-legality-model.md` point 5), not something that varies by environment the way the legal-set pool does. Read it fresh each time; it changes when Riot publishes updates (most recently 2026-07-24). If there's any doubt the local list is current, cross-check against the live official ban list at `https://playriftbound.com/en-us/rules-hub/` (see the library's top-level "route, don't snapshot" rule) before telling someone a card is safe to play in a real event.
- **Construction legality**: exactly 40 main deck (including the Chosen Champion), exactly 1 Legend, exactly 12 runes (separate pile, no copy cap, ideally split 6/6 — see methodology), exactly 3 Battlefields, max 3 copies of any card name elsewhere (the Champion's extra copies count toward its own cap). A deck's two Domains are fixed entirely by its Legend — Riftbound does not allow the "however many colors you want" flexibility some other TCGs have. Verify this against the official Core Rules PDF (or a private companion's pointer to the local encoded ruleset) rather than restating from memory if precision matters.

## Deckbuilding methodology

This is the part that separates "knows the rules" from "can actually help build a good deck." Sourced from riftbound.gg's Deckbuilding 101 and archetype-theory writeups (community/publisher analysis, cite as such, re-verify if it's been a while since 2026-08 — the game is young and this thinking is still settling) plus the transferable core of general TCG theory (card advantage / tempo trade-offs are near-universal across the genre).

**Start from the Legend, not from a pile of strong cards.** The Legend fixes your two Domains and provides an ability that should shape everything else — synergy with that one ability beats a collection of individually powerful cards pulling in different directions. Read the Legend's and both Champion options' printed text before suggesting anything; the ability itself usually signals the intended archetype (a unit-buff-on-defense Legend signals midrange/control, a discard-to-draw Legend signals aggro) more reliably than the Domain pairing alone. Two Legends can share both Domains and still want opposite gameplans — don't assume Domain pair alone determines archetype.

**Three archetypes, defined by path to the same win condition.** Points come from capturing and *holding* Battlefields — this is not a damage race, and that changes what "a good curve" means versus other TCGs. Aggro floods the board and forces early decisions before the opponent stabilizes. Control denies space and grinds out points by holding Battlefields over time. Combo plays a patient setup game, then detonates a turn that swings multiple points at once, trading consistency for ceiling. State which one a deck is going for explicitly — a deck that doesn't commit to a lane usually just plays worse versions of all three.

**Domain personality** (community-sourced sketch, not finalized doctrine — treat as a starting hypothesis to verify against actual card text, not a fixed truth): Fury (紅) leans most aggressive; Order (黃) leans board-control; Mind (藍) is spell-dense, natural combo territory; Chaos (紫) mixes spells with mobility/cunning plays; Calm (綠) emphasizes movement and winning showdowns; Body (橙) runs fewer, bigger units with a rune-recycling bent. Use this to form a hypothesis about a Domain pair's texture, then confirm or revise it against what the actual legal card pool in those Domains contains for the environment in question (a much larger sample in Global Standard than in Taiwan) — don't state it as fact without checking.

**Main deck composition** (numbers are a starting point to adjust, not a hard formula): roughly 9–12 low-cost units so the early game is never empty-handed, 6–9 low-to-medium cost spells (many spells are reactive — a single well-timed one often decides a close Showdown) plus a few bigger ones as the ceiling, and more units than spells overall since units are what actually holds Battlefields. Because the win condition is board/Battlefield control rather than a damage race, over-investing in expensive endgame closers at the cost of an empty early game is a sharper mistake here than in a life-total-race TCG — a deck that can't contest the board on turns 2–4 may never get to cast its finishers.

**Rune split**: start from 6 runes of each Domain, and skew toward 5/7 or 4/8 only when the deck's actual power-cost distribution across the two Domains is genuinely lopsided (one Domain carrying most of the expensive cards) — check the real distribution against your card database rather than guessing.

**Card-quality-by-rarity as a deckbuilding role, not a power ranking**: Commons are the consistency backbone (early plays, keeps the draw engine functional) — a deck too light on commons will feel inconsistent even with strong top-end. Uncommons bridge early setups into the midgame. Rares often define the actual win condition. Epics are typically 1–2 copy, high-cost, game-ending plays, not something to build a deck's core around.

**Chosen Champion and Signature cards**: a Legend has two Champion options in its Domains — pick whichever matches the deck's committed gameplan, not automatically the higher-rarity one. Every Legend also has Signature cards tied to its Champion Tag (up to 3 total, regardless of which specific Champion is chosen) — these are frequently above the average power level for their cost and worth checking even when not obviously "needed."

**Battlefield selection**: pick from two angles — which three synergize best with the deck's own plan (a control deck wants different Battlefield effects than an aggro one), and, for best-of-three, how the pick sequences across game 1 (often randomly assigned), game 2, and a potential tiebreaker game.

**Process**: don't judge or swap cards after one or two games. A deck's real strengths and losing patterns only show up over repeated play — "why did this deck lose" is more diagnostic than "did this deck win."

## "Does this classic/tournament deck still work?" — the ban-substitution workflow

Someone points at a known decklist (an official RQ Top 8, a practice deck already in this site's guides, something pasted from overseas) and asks if it still holds up — in whichever environment applies (see "Which environment: pick before answering" above; this workflow runs identically in either, only the legal-set check in step 1 differs).

**Default assumption, not an edge case**: anything sourced from the game's early global history (roughly its first ban wave's worth of time, i.e. anything that looks like it predates 2026-03-31) should be assumed to need this workflow, not just checked in passing — see `references/regional-legality-model.md`'s "compound gap" section for why a newly-arrived region's Set 1 pool already has some of its own defining cards pre-banned. That reasoning applies most sharply to the Taiwan environment; Global Standard has no regional lag, but a pre-ban-wave decklist still needs the same card-by-card ban check there too. Don't skip straight to "looks legal" on a classic decklist without running it through the steps below.

1. Check the Legend/Champion first, separately from everything else, against whichever environment's legal-set list applies. In Taiwan, if it's from a set outside OGN+OGS+ARC entirely, the honest answer is "not buildable here at all" — don't bury that under a list of minor substitutions. In Global Standard this step almost never disqualifies a Legend (nearly everything released is legal there) — it mainly matters for a genuinely new/preview set that hasn't released yet.
2. Check every other card against the actual current ban list — get the exact banned names from the real list, not a guess or a memory of an older version.
3. For each banned non-Legend card, read its actual printed effect and place it in the methodology above: what role was it playing (an aggro deck's cheap presser, a control deck's stabilizer, a combo piece, a Battlefield's conditional bonus)?
4. Search the legal, non-banned pool for cards in the same Domain(s) filling a similar role at a similar cost — not just a similarly-costed card, the same *job*. Only recommend a specific card once you've confirmed its real text and legality; don't suggest from vague recollection.
5. Give the honest verdict: still fully functional with swaps, meaningfully weaker but playable, or the archetype's core game plan doesn't survive without that piece. All three are legitimate answers — don't default to reassurance just because it's more pleasant to hear.

## No metagame-defining claims

No win-rate/play-rate/Tier/"best deck" claims anywhere in the text, in either environment. This applies even where meta data plausibly exists (tournament results in Global Standard, for instance) — Riot's Developer Portal policy for Riftbound apps (`developer.riotgames.com/policies/riftbound`) explicitly restricts apps that "publish or retain metagame-defining data" (win rate / play rate / matchup win% differential), independent of whether the data is available. Staying qualitative is what keeps this kind of tool inside the Approved-use "Deck builders / Card libraries" category instead of drifting into the restricted one.
