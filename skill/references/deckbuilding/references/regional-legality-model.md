# Regional legality is a general problem, not a Taiwan quirk

Riftbound's global card pool grows on its own release cadence (a new numbered set roughly every 2–3 months as of 2026). Any single market's *actual legal pool* is set by that market's own localization and distribution deal, which runs on a completely separate clock. These two clocks are not the same, there's no default assumption that they converge, and this isn't a one-off Taiwan situation — it's a structural feature of how Riftbound is rolling out worldwide, and it will recur every time the game enters a new language or region.

**This already happened once and is about to happen again.** Taiwan's Traditional-Chinese Set 1 (OGN) launched 2026-08-07 — by which point the *global* (English/Simplified-Chinese) pool had already reached Set 4 (Vendetta, 2026-07-31). Taiwan entered the game already three sets behind global, with no confirmed date for its own Set 2. Korea's official launch is confirmed for September 2026, and it also starts from Set 1 ("Origin") — the same lag pattern, a few weeks later, in a different market. Expect this again in any future region (Japan and the rest of APAC are openly discussed as "next," per Riot's own 2026 roadmap commentary, with no date set yet).

**Language tracks are not guaranteed to sync with each other.** Riot announced (2026-02-04) that Simplified Chinese and English would reach release-date parity starting with Set 4 — but that announcement explicitly covers only those two tracks. Traditional Chinese (Taiwan/Hong Kong/Macau) is licensed to a different distributor (Glorious Soul HK Limited) than Simplified Chinese (Shining Soul), and was not included in that parity commitment. Don't assume a region will inherit another region's catch-up schedule just because they share a script, a publisher relationship, or physical proximity — check that specific region's own confirmed facts.

## The compound gap: a new region's "Set 1" is not the original Set 1

Fewer sets is the visible half of the problem. The other half is easy to miss and doesn't go away when the set-count gap eventually closes: **a new region's day-one legal pool already carries the accumulated ban history of an environment that region never got to play.** The pioneer region (English/Simplified Chinese) experienced an actual period of Set 1 with zero bans — Riftbound's ban list didn't exist until 2026-03-31, by which point global was already into Set 2. A region that launches Set 1 later than that date, like Taiwan (2026-08-07), never gets that unbanned period at all. Their "Set 1" arrives pre-stripped.

This isn't hypothetical for Taiwan — it's already the case. Of the first ban wave (2026-03-31), five of the seven banned items are themselves OGN (Set 1) cards: **Fight or Flight (OGN-168), Scrapheap (OGN-182)**, and the battlefields **The Dreaming Tree (OGN-292), Obelisk of Power (OGN-284), Reaver's Row (OGN-285)**. These were part of the "Miracle" Chaos deck that defined the pioneer region's own early Set-1 metagame — the community writeups this skill's deckbuilding methodology cites (riftbound.gg's Deckbuilding 101 and similar) were largely written about *that* Set-1 era. A region arriving after the ban never gets to run that line at all, even though the cards are physically in their starter/booster product.

**Worse, the gap is likely to widen, not close.** Riot's own stated reasoning for banning Fight or Flight/Scrapheap was explicitly forward-looking: "as the card pool expands, cards that support this type of strategy will only become more powerful" — i.e. some Set-1 bans are calibrated against a multi-set card pool the newly-arriving region doesn't have access to at all, not against problems that Set-1-alone would necessarily produce in isolation. Bans are one global list (see point 5 below), not scoped per region's actual accessible pool. As Riftbound keeps expanding globally (~a new set every 2–3 months) and keeps banning to keep pace with that larger pool, every subsequent region that starts from "Set 1" inherits a longer accumulated ban history relative to the still-small card pool they actually have. There's no announced mechanism that shrinks this gap — it compounds with each future region's launch, not just Taiwan's.

**Practical consequence**: don't treat "classic Set 1 decklist from the pioneer region" as occasionally needing the ban-substitution workflow (below in the main deckbuilding book) — assume by default that anything sourced from the game's early global history needs it, since the environment it was built in has already been partially legislated out of existence everywhere, for every region, including the one that hasn't opened its first pack yet. And don't repeat a community source's "X is a strong line" claim without checking X against the live ban list first — a claim written about the original Set-1 era may be describing something that no longer exists in playable form anywhere.

## The method

1. **Establish the region's confirmed release facts only.** What's actually confirmed on shelves or with a confirmed date, not what "should" follow from the global pace. Silence about a region's next set is not evidence either way — don't extrapolate optimism or pessimism from an absence of news.
2. **Watch for region-only bundled products.** A region's launch often ships a companion/promo product alongside the main numbered set (Taiwan's OGS Proving Grounds starter set, China's FND simplified-Chinese-only promo series) that isn't part of the main numbered-set sequence but is still part of that region's real legal pool. A check that only walks the numbered-set list will silently miss these — verify against the region's own distributor/launch announcements, not just a global set-code list.
3. **Track the region's own next-set date separately from global's.** State "no confirmed date" plainly when that's the truth, rather than guessing a catch-up timeline in either direction.
4. **The legality boundary should live in exactly one implementation spot.** When a region does get a new set, whatever encodes "which sets are legal here" (a set-order threshold in a deckbuilder's matching logic, a config value, whatever this deployment actually uses) needs to move in that one place — not be re-stated separately in prose documentation and in code, where one gets updated and the other quietly goes stale. If both exist, update both in the same change and say so.
5. **Bans are usually company-wide, not regional.** Riftbound's Constructed ban list applies globally regardless of which sets a given region has access to — don't assume a region's card-pool lag also implies a region-specific ban list. Layer the (usually global) ban list on top of whatever the region's own legal-set pool is; they're independent axes, not the same problem.

## Applying the model: Taiwan today (worked example)

As of last verification (2026-07-19 — this is a dated snapshot, re-check a live/current source before relying on it): Taiwan's legal pool is **OGN + OGS + ARC** (the Arcane crossover promo bundled during the Set 1 window), treated together as "Set-1-available." SFD (Spiritforged) onward is flagged as requiring a later set the region doesn't have yet. There is no confirmed Taiwan Set 2 date. When one is announced, whatever implements the set-order threshold and whatever tracks these facts in prose both need updating together — see point 4 above.
